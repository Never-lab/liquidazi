# Ads Stub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship non-invasive ad placeholder slots (desktop side rails + end-screen banner) behind a kill switch, with no third-party scripts and no sim impact.

**Architecture:** Pure `adsStubEnabled()` for env rules (unit-tested in node). Presentational `AdSlot` with `placement` id. GameHUD wraps the desk with left/right rails (CSS ≥1200px). EndScreen mounts `end-banner` below outcome summary. Future networks replace only the stub body inside `AdSlot`.

**Tech Stack:** React 19, TypeScript, CSS modules, Vite `import.meta.env`, Vitest (node). No new npm deps.

**Spec:** `docs/superpowers/specs/2026-08-08-ads-stub-design.md`

## Global Constraints

- Placement C: `rail-left`, `rail-right`, `end-banner` only
- Provider D: stub UI only — no AdSense/ethical tags, no iframes, no ad cookies
- Italian label: **“Spazio advertiser”**
- Optional sponsor link only if `VITE_ADS_SPONSOR_URL` is set
- Kill switch: default **on when `import.meta.env.PROD`**; `VITE_ADS_STUB=0` forces off; `VITE_ADS_STUB=1` forces on
- When off: render `null` (no empty layout holes)
- Rails: desktop ≥1200px only; mobile = end banner only
- Never overlay Commesse / Chiudi mese / event modals
- No sim / progression / pay-to-win changes
- `npm run lint && npm test && npm run build` green per task commit

- [ ] **Step 2: Run — expect FAIL**

- [ ] **Step 3: Implement**

Create `src/ui/adsStub.ts`:

```ts
export type AdPlacement = "rail-left" | "rail-right" | "end-banner";

type AdsEnv = {
  PROD?: boolean;
  VITE_ADS_STUB?: string;
};

/** Kill switch: explicit VITE_ADS_STUB wins; else on only in production builds. */
export const adsStubEnabled = (env?: AdsEnv): boolean => {
  const e = env ?? {
    PROD: import.meta.env.PROD,
    VITE_ADS_STUB: import.meta.env.VITE_ADS_STUB as string | undefined,
  };
  if (e.VITE_ADS_STUB === "0") return false;
  if (e.VITE_ADS_STUB === "1") return true;
  return Boolean(e.PROD);
};
```

- [ ] **Step 4: Run — expect PASS**

Run: `npx vitest run src/ui/adsStub.test.ts`

- [ ] **Step 5: Commit**

```bash
git add src/ui/adsStub.ts src/ui/adsStub.test.ts
git commit -m "feat(ads): add ads stub kill-switch helper"
```

### Task 2: `AdSlot` stub component

**Files:**
- Create: `src/components/AdSlot.tsx`
- Create: `src/components/AdSlot.module.css`

**Interfaces:**
- Consumes: `adsStubEnabled`, `AdPlacement` from Task 1; `import.meta.env.VITE_ADS_SPONSOR_URL`
- Produces: `AdSlot({ placement: AdPlacement })` → stub or `null`

- [ ] **Step 1: Implement component + CSS**

`src/components/AdSlot.tsx`:

```tsx
import { adsStubEnabled, type AdPlacement } from "../ui/adsStub";
import styles from "./AdSlot.module.css";

type Props = { placement: AdPlacement };

const sizeClass: Record<AdPlacement, string> = {
  "rail-left": styles.rail,
  "rail-right": styles.rail,
  "end-banner": styles.banner,
};

export const AdSlot = ({ placement }: Props) => {
  if (!adsStubEnabled()) return null;

  const sponsor = import.meta.env.VITE_ADS_SPONSOR_URL as string | undefined;
  const href = typeof sponsor === "string" && sponsor.trim() ? sponsor.trim() : null;

  return (
    <aside
      className={`${styles.slot} ${sizeClass[placement]}`}
      data-placement={placement}
      aria-label="Spazio advertiser"
    >
      <p className={styles.label}>Spazio advertiser</p>
      {href ? (
        <a className={styles.link} href={href} target="_blank" rel="noopener noreferrer">
          Diventa sponsor
        </a>
      ) : null}
    </aside>
  );
};
```
